# Truong Anh Duong — Portfolio

Personal portfolio built with Next.js 15 and Tailwind CSS, exported as a static site and deployed to GitHub Pages.

- Live: https://duongtac22.github.io/
- Run locally: `npm install` then `npm run dev`
- Deploy: push to `master`; the GitHub Actions workflow builds and publishes automatically.

Project screenshots live in `public/projects/`. Edit content in `app/page.tsx`.
